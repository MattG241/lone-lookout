# Lone Lookout

A quiet first-person exploration game for the **Nintendo Wii** (Homebrew Channel). You spend the
end of a fire season as the lookout on Kestrel Knob in the fictional **Ashen Peaks**: walk, look,
listen, sit, and talk on the radio with Dot at Basin Station. No combat, no timers, no fail states.

## What's here so far

- **[`docs/DESIGN.md`](docs/DESIGN.md)** is the full design document: pillars, story, day
  structure, controls, map, radio outline, art and audio direction, and technical plan.
- **`tools/worldgen/ashen_peaks.py`** is the single source of truth for the map (terrain features,
  areas, trails, vegetation masks). It renders the notebook map now and will bake the in-game
  terrain in Phase 3.
- **`tools/concept/style_frame.py`** is the "Soft Paper Peaks" concept renderer behind the images
  in `docs/concept/`.
- **`data/palette/time_of_day.json`** is the colour script for the day/night cycle.

Regenerate the concept images (Python 3.10+, `numpy`, `Pillow`):

```sh
python3 tools/worldgen/ashen_peaks.py --summary --map docs/concept/ashen_peaks_map.png
python3 tools/concept/style_frame.py --out docs/concept
```

The images in `docs/concept/` are design mock-ups from these scripts, **not** Dolphin screenshots.
Real captures start in Phase 2.

## Building the game

Coming in Phase 2. The plan is devkitPro (devkitPPC + libogc + libfat) with `make` producing
`lonelookout.dol`, run in Dolphin or from the Homebrew Channel. See DESIGN.md §11.

## Originality

Every asset is generated by tools in this repository: textures, models, the hand-lettered font,
music and sound effects. No third-party game assets are used.
